# Organización del Computador

Arquitectura de computadoras, representación de la información y programación en **Assembler** (8086 y ARM).

## Contenido

Material organizado por unidades:

| Unidad | Tema |
| --- | --- |
| [`U1_SistemasDeNumeracion/`](U1_SistemasDeNumeracion/) | Sistemas de numeración, punto flotante, decimal empaquetado. |
| [`U2_MaquinaElemental/`](U2_MaquinaElemental/) | Máquina de Brookshear, set de instrucciones. |
| [`U3_ArquitecturaDelConjuntoDeInstrucciones/`](U3_ArquitecturaDelConjuntoDeInstrucciones/) | ISA, set de instrucciones 8086. |
| [`U4_Assembler/`](U4_Assembler/) | Assembler, compilación y ensamblado, macros. |
| [`U5_Componentes/`](U5_Componentes/) | Componentes del computador: procesador y memoria. |
| [`U6_AlmacenamientoExterno/`](U6_AlmacenamientoExterno/) | Almacenamiento secundario: discos, medios ópticos. |

Además:

- `FINAL-Práctica.pdf`, `orga.docx`, `resumen masomenos de orga.pdf` — Resúmenes y práctica para el final.
- `ejemplo_final.txt`, `final12-02.txt`, `parcial de practica.txt` — Ejercicios y modelos de parcial/final.
- [`Org. Computador/`](Org.%20Computador/) — Carpeta con el material **completo** de la cursada (bibliografía, libros, ARM, parcialitos, PPTs y guías resueltas por unidad).

> ⚠️ **Nota:** la carpeta `Org. Computador/` es una copia más completa que en parte se solapa con las carpetas `U1…U6` de arriba. Conviene unificar ambas en algún momento para evitar duplicados.
