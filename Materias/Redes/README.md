# Redes

Material de la materia **Redes**: telecomunicaciones, medios de transmisión, modelo de capas, protocolos y enrutamiento.

Las PPTs son de la cátedra (Ing. Marcelo E. Volpi, Ing. Lucas Giorgi, Ing. Vanesa Llasat). El material se va sumando clase a clase.
