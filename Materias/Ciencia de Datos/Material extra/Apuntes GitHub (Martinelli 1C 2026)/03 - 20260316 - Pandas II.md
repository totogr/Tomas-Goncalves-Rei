## Clase 3 - Pandas II

Si quisiéramos unir dos DataFrames en uno solo (es decir, agregando a las columnas de uno los datos del otro), podemos usar el método de Pandas `concat()`. Me devolverá un solo DataFrame conteniendo todas las filas de los DataFrames pasados.

```python
nueva_df = pd.concat([df1, df2, df3])
```

Para calcular los coeficientes de correlación entre columnas de un DataFrame, usamos el método de DataFrame `corr()`.

```python
c = df.corr()
c.loc["colA", "colB"] # Devuelve el coeficiente de correlación entre las columnas A y B.
c.loc["colA", "colB"] = 0.5 # Sobreescribimos el coeficiente de correlación.
```

Se puede usar el método de DataFrame `pivot()` para crear un nuevo DataFrame modificando la estructura del original. Es un mecanismo de *reshaping* del DataFrame.

```python
df.pivot("colA", "colB", "colC")
# La columna A pasa a ser el índice del DataFrame.
# Los valores de la columna B me determinan las columnas del nuevo DataFrame.
# La columna C tiene los valores que deberán aparecer en las nuevas columnas del DataFrame generadas por la columna B.
```

El método `fillna()` se puede aplicar tanto a DataFrames como a series. Con él definiremos qué valores pondremos en lugar de los que están en `NaN`. Las operaciones de agregación, por ejemplo, no tienen en cuenta los valores rellenos con `NaN`. Al reemplazar el valor, los resultados comienzan a incluirlos en sus operaciones.

```python
df.fillna(0) # Reemplaza los valores 'Nan' con el número 0.
```

Podemos usar `pivot_table()` con el mismo objetivo que `pivot()`, pero sin necesidad de pasar por la agrupación previa de datos con `groupby()`.

```python
df.pivot_table(values="colC", index="colA", columns="colB", aggfunc="count")
# El resultado de haber utilizado este método sería similar al de haber usado 'pivot()' en el ejemplo de más arriba.
```

- Sin embargo, aunque parezca que sí, los métodos no arrojan exactamente los mismos resultados. Si agregamos el parámetro `fill_value` a `pivot_table()` (rellena con ese valor los `NaN`), veremos que el tipo de dato obtenido en el nuevo DataFrame puede ser distinto al obtenido luego de usar `groupby()` seguido de `pivot()`.

Usamos el método de DataFrame `sort_values()` para ordenar los datos de forma creciente o decreciente según las columnas especificadas. Se puede utilizar el parámetro `inplace` para pedir que se realice el ordenamiento en la misma estructura, en lugar de generar una nueva.

Podemos utilizar el método `transform()` luego de un `groupby()` para realizar cálculos basados en esos grupos, pero **manteniendo la misma estructura y número de filas del DataFrame o la serie original**. Por ejemplo, podría servir para generar nuevas columnas de datos agregados, como el promedio o la suma de cada grupo, para comparar ese valor fijo con el de cada fila individual.

Para definir ***outliers*** en nuestro DataFrame (datos que se alejan mucho del promedio general de los datos obtenidos), usamos el desvío estándar. En este caso asumimos que los datos se comportan siguiendo una distribución normal, pero podrían dejar de servir si siempre lo consideramos de esta manera. Usualmente, se suele definir que un dato es *outlier* si está por fuera del rango `[mean + 3*σ, mean - 3*σ]`, es decir, considerando el triple del desvío estándar obtenido.

Usamos el método de DataFrame `set_index()` para mover ciertas columnas al apartado de índices. Esto no significa que se vayan a eliminar datos repetidos o que se vayan a considerar solo valores únicos. En Pandas no existe una restricción que indique que los índices deban ser únicos. Al setear nuevos índices, puedo utilizar `loc()` para acceder a filas de índices específicos. 

Podemos usar el método de GroupBy `apply()` para **aplicar una función específica a una columna o a una fila**. Si le definimos el *axis*, podremos operar fila a fila (con el valor `1`). Siempre que se pueda, evitar el uso del método (tarda mucho más en procesar la consulta, suelen haber formas más veloces).
