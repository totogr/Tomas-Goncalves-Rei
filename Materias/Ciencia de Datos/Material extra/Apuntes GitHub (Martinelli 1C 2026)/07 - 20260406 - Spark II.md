## Clase 7 - Spark II

### Joins

Se hacen por **clave** (debe haber clave/valor para poder operar).

- **Inner Join**: devuelve todos los pares de elementos para cada clave, en particular **los que hay en común en ambos sets por esa clave**. Se usa `rddA.join(rddB)`.
- **Left Outer Join**: se devuelven todos los datos del RDD izquierdo, completando con los derechos (nulos si no coincide la clave). Se usa `rddA.leftOuterJoin(rddB)`.
- **Right Outer Join**: se devuelven todos los datos del RDD derecho, completando con los izquierdos (nulos si no coincide la clave). Se usa `rddA.rightOuterJoin(rddB)`.
- **Outer/Full Join**: se devuelven los datos de ambos RDDs, rellenando con nulos si no coinciden las claves. Se usa `rddA.fullOuterJoin(rddB)`.
- **Broadcast Join**: 
	- **Variable broadcast**: permite mantenerla de solo lectura *cacheada* en cada nodo del cluster para rápido acceso. 
	- Son útiles cuando se necesita la **misma información muchas veces**.
	- Se puede usar cuando uno de los RDDs es lo suficientemente pequeño para que pueda ser enviado como variable local a los nodos (*brodcasteado*).
	- Se usa `sc.broadcast(x)` para brodcastear la variable `x`.

### Union, Intersección y Diferencia

- **Union**: obtiene la unión entre dos RDD usando `rddA.union(rddB)`.
- **Intersection**: obtiene la intersección entre dos RDD usando `rddA.intersection(rddB)`.
- **Subtract**: obtiene los elementos de un RDD quitándose los que también aparecen en el otro. Se usa `rddA.subtract(rddB)`.

### Cache

Se pueden cachear RDDs para poder **acceder rápidamente** a ellos si los voy a usar muchas veces, **sin tener que recalcular operaciones**.

- **Objetivo**: no recalcular operaciones para obtener esos registros.
- **Recomendación**: solo *cachear* si se lo va a usar varias veces en el futuro, y si los conjuntos de dato son lo suficientemente pequeños como para poder hacerlo sin problemas.

Se usa el método `rdd.cache()` para *cachear*. Es una **transformación**, por lo que solo se efectúa una vez realizada una **acción** posterior sobre el RDD.
