## Clase 2 - IA 2

### 1. MCP (Model Context Protocol)

Se define como el **"USBC para las aplicaciones de IA"**. Es un estándar de código abierto que permite conectar aplicaciones de IA (como ChatGPT, Claude o IDEs agénticos como Cursor) con servicios externos (bases de datos, GitHub, Google Calendar) sin necesidad de desarrollar integraciones personalizadas para cada una.

- **Funcionamiento:** Utiliza una arquitectura **cliente-servidor**.
    - **MCP Host:** Es el entorno donde vive la IA (ej. Claude Desktop).
    - **MCP Client:** Establece conexiones uno a uno con los servidores.
    - **MCP Server:** Procesos separados que proporcionan tres elementos clave: **Contexto** (documentos), **Tools** (acciones ejecutables) y **Prompts** (plantillas de comportamiento).
- **Capas Técnicas:**
    - **Data Layer:** Define el protocolo de comunicación mediante **JSON-RPC 2.0**.
    - **Transfer Layer:** Gestiona la comunicación a través de **HTTP** (servidores externos) o **STDIO** (servidores locales).

### 2. Toolbox (Google)

Es un protocolo de código abierto de Google para interactuar con **bases de datos** mediante lenguaje natural.

- **Funcionamiento:** Actúa como un intermediario que traduce solicitudes en lenguaje humano a consultas **SQL**. En la demo de la clase, se utilizó para gestionar reservas de hoteles en un servidor **Postgres**: el usuario pide buscar un hotel o cambiar una fecha, el Toolbox genera la query, Postgres devuelve filas y columnas, y el Toolbox traduce ese resultado de vuelta a una respuesta amigable para el usuario.

### 3. N8N

Se presenta como una alternativa o complemento al MCP para la **automatización de flujos de trabajo**.

- **Funcionamiento:** Permite crear **DAGs** (Grafos Acíclicos Dirigidos) donde un **Trigger** (disparador) inicia una serie de nodos de procesamiento. A diferencia de MCP, que es más un conector directo bajo demanda, N8N está pensado para procesos más complejos que requieren orquestación paso a paso sin escribir código, utilizando una interfaz visual.

### 4. NotebookLM

Es una herramienta de Google diseñada para asistir en el **estudio y la investigación**.

- **Funcionamiento:** El usuario carga fuentes de información (archivos, textos, imágenes) y la herramienta permite interactuar con ellas mediante chat. Puede generar automáticamente **resúmenes, guías de estudio, audios, videos y cuestionarios** basados exclusivamente en el material proporcionado.

### 5. SDD (Spec-Driven Development) y Kiro

Se introduce el concepto de **Desarrollo Dirigido por Especificaciones** como la próxima capa de abstracción en la programación.

- **Funcionamiento de SDD:** En lugar de escribir código línea por línea, el desarrollador redacta **Specs** (instrucciones funcionales en lenguaje natural) que describen lo que el software debe hacer. Agentes de IA interpretan estas especificaciones para generar el código automáticamente.
- **Herramienta Kiro:** Es un IDE agéntico de Amazon que sigue este flujo: se definen los **Requerimientos** (historias de usuario), luego el **Diseño** (arquitectura) y finalmente se ejecutan las **Tareas** de generación de código.
