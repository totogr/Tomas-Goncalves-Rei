## Clase 16 - NLP II

### I. Series de Tiempo

El objetivo principal es trabajar con datos donde el **orden temporal es fundamental** y las observaciones no son independientes entre sí.

Conceptos y Herramientas:

- **Diferencia con datos tradicionales:** A diferencia de un dataframe común, aquí el tiempo actúa como un índice útil que permite ver la evolución de las variables.
- **Hipótesis de predicción:** Se asume que el valor futuro puede calcularse en función de los datos previos (aunque con limitaciones en casos como el precio del dólar).
- **Feature Engineering (Lagged Features):** Si no se usan redes neuronales, se deben crear variables manualmente, como los valores previos (t−1,t−2), promedios móviles o varianza de la ventana actual.
- **Redes Neuronales Recurrentes (RNN):**
    - **Funcionamiento:** Tienen "memoria" gracias a conexiones laterales entre neuronas que permiten propagar información de una iteración a la siguiente.
    - **Arquitecturas específicas:** Se mencionan las **LSTM** (excelentes para patrones de largo plazo) y las **GRU** (más rápidas y eficientes para dependencias locales).
- **Validación Temporal:** Es crucial **no usar un split aleatorio**. Se debe tomar, por ejemplo, el primer 80% de los datos para entrenamiento y el 20% final para validación/testeo, evitando así "filtrar" información del futuro al modelo.

### II. NLP 2: De Word2Vec a Transformers

Este bloque recorre la evolución desde la representación de palabras aisladas hasta el análisis de secuencias complejas.

Herramientas y Evolución:

1. **Word2Vec:**
    - **Funcionamiento:** Representa las palabras en un espacio geométrico basado en su contexto (usando algoritmos como _Skip-gram_).
    - **Resultado:** Permite relaciones matemáticas sorprendentes, como "Rey - Hombre + Mujer = Reina".
2. **Mecanismo de Atención (Attention):**
    - **Funcionamiento:** Permite que el modelo, al procesar una palabra, identifique qué otras palabras del texto son relevantes para entender su significado.
    - **Ventaja:** A diferencia de las RNN tradicionales (como _Seq2Seq_), la atención es **paralelizable** y no pierde información en textos largos.
3. **Transformers:**
    - **Arquitectura:** Basada en el paper _"Attention is All You Need"_, introduce el **Positional Encoding**, que inyecta la posición de cada palabra en el dato mismo, ya que el Transformer no procesa de forma secuencial nativa como una RNN.
    - **Variantes:** Se dividen en **Encoder-only** (útiles para extraer features y clasificar, ej: BERT) y **Decoder-only** (modelos generativos, ej: GPT).
4. **Named Entity Recognition (NER) con BERT:**
    - **Funcionamiento:** Es una tarea de etiquetado de tokens donde el modelo identifica entidades (personas, lugares, fechas).
    - **Caso Práctico:** En la clase se muestra cómo usar un modelo BERT para detectar "secretos" (passwords o API keys) en código fuente.
    - **BIO Labeling:** Técnica para clasificar si un token es el inicio (**B**eginning), está dentro (**I**nside) o fuera (**O**utside) de una entidad.
5. **Fine-Tuning y Softmax:**
    - **Transfer Learning:** Se toma un modelo pre-entrenado (BERT), se descarta su "cabezal" de clasificación original y se le añade uno nuevo para la tarea específica (detectar credenciales).
    - **Softmax:** Se aplica al final para convertir los resultados de la red (_logits_) en una distribución de **probabilidad (confidence)** entre las clases posibles.

Problemas comunes detectados:

- **Catastrophic Forgetting:** Riesgo de que, al re-entrenar un modelo para una tarea nueva, este olvide lo que ya sabía (ej: entender el idioma inglés). Se soluciona usando tasas de aprendizaje muy bajas y técnicas como _clipgrad_.
- **Overfitting:** El modelo se aprende los ejemplos de memoria (ej: reconoce solo las API keys que vio en el entrenamiento) y no logra generalizar ante código nuevo.

### VIDEOS TEÓRICOS

#### 1. Deep Learning sobre Time Series: RNNs (Redes Neuronales Recurrentes)

Este video explica cómo las redes neuronales pueden abordar datos secuenciales donde el orden temporal es fundamental.

- **Concepto de Memoria:** A diferencia de las redes densas tradicionales, las RNN tienen conexiones laterales entre neuronas que permiten propagar información de un instante a otro, creando una "memoria" interna.
- **Funcionamiento:** La neurona recibe el valor actual (t) y lo combina con su estado interno del instante anterior (t−1) mediante pesos ajustables (w), generando una salida y un nuevo estado para el futuro.
- **Problemas de Gradiente:** Las RNN clásicas sufren de _vanishing_ y _exploding gradients_. Al retropropagar el error a través de muchas capas temporales, los pesos pueden desvanecerse (hacerse cero) o estallar (hacerse infinitos), lo que les impide aprender dependencias de largo plazo.
- **Arquitecturas Especializadas:**
    - **LSTM (Long Short Term Memory):** Introduce "compuertas" (olvido, entrada y salida) que deciden qué información mantener o descartar, siendo mucho más resistentes a los problemas de gradiente y mejores para secuencias largas.
    - **GRU (Gated Recurrent Units):** Una versión simplificada de las LSTM. Son más rápidas de entrenar al tener menos parámetros, aunque retienen un poco menos de información.

#### 2. Deep Learning sobre Time Series: Convoluciones (CNN 1D)

Se presentan las convoluciones en una dimensión como una alternativa eficiente a las RNN para procesar secuencias temporales.

- **Funcionamiento:** Se utiliza un **kernel** (una ventana pequeña) que se desliza sobre la serie de tiempo, multiplicando y sumando los valores para extraer características locales.
- **Ventaja de Velocidad:** Al no depender del estado anterior para procesar el siguiente instante, las convoluciones son totalmente **paralelizables** y mucho más rápidas que las RNN.
- **Hiperparámetros de la Convolución:**
    - **Kernel Size:** Define cuántos instantes de tiempo ve el modelo a la vez.
    - **Stride:** Es el salto que da el kernel; permite acortar el largo de la serie de salida.
    - **Dilatación:** Permite que el kernel vea instantes de tiempo de forma intercalada, logrando una visión de contexto más amplia sin aumentar la cantidad de parámetros.
- **Pooling:** Operación para colapsar la serie temporal en un vector de características fijas.
    - **Max Pooling:** Toma el valor máximo de una ventana, ideal para detectar si un patrón específico se activó en algún momento (ej. detección de fallas).
    - **Average Pooling:** Toma el promedio, capturando tendencias generales o medias móviles.

#### 3. Representaciones Vectoriales: Word2Vec, FastText y Char Embeddings

Se explica cómo transformar palabras en números (vectores) manteniendo su significado semántico.

- **Hipótesis Distribucional:** Se basa en la idea de que el significado de una palabra está determinado por las palabras que la rodean ("con quién anda").
- **Word2Vec:**
    - **Funcionamiento:** Entrena vectores para cada palabra de modo que palabras con contextos similares terminen cerca en el espacio geométrico.
    - **Capacidad Matemática:** Permite realizar operaciones lógicas como "Rey - Hombre + Mujer = Reina".
    - **Limitación:** Si una palabra no está en el vocabulario de entrenamiento, se asigna a un vector "unknown" (desconocido), perdiendo toda su información estructural.
- **FastText:**
    - **Funcionamiento:** Divide las palabras en combinaciones de letras (**n-grams**). El vector final de una palabra es la suma de los vectores de sus partes.
    - **Ventaja:** Puede inferir el significado de palabras que nunca vio si reconoce sus raíces o sufijos (ej: asocia "salar" con "sal").
- **Char Embeddings:**
    - **Funcionamiento:** Se crean vectores para caracteres individuales y se procesan con convoluciones para formar la representación de la palabra. Es una forma liviana y eficiente de extraer significado de la estructura interna de los tokens.
- **Transformers (Mención):** Se destacan como el estado del arte actual (basados en el mecanismo de atención), superando a las RNN por ser más rápidos y capturar mejor el contexto global.
