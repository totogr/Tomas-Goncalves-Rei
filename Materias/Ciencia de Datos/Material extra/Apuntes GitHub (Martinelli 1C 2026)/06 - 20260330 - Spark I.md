## Clase 6 - Spark I

Se necesita **procesar grandes volúmenes de datos**.

**Map-Reduce**: procesamiento distribuido de datos usando uin **cluster de computadoras**.

**Cluster**: conjunto de computadoras que trabajan juntas y pueden ser vistas como un *sistema único*.
- Cada computadora es un **nodo**.
- Cada nodo puede ser una computadora estándar (como la de los hogares).
- Los nodos se comunican y conectan entre sí.

### Almacenamiento distribuido

- **FileSystem distribuido**: los bloques de archivo pueden estar en distintos nodos.
- Gestionar **cómo y dónde** guardar información en una computadora, y cómo consultarla.
- Almacenar grandes volúmenes de datos en muchos equipos.
- Replicar datos y ser tolerante a fallos.
- Alta disponibilidad y bajo costo relativo.

**Implementaciones**:
- GFS (Google)
- HDFS (Apache Hadoop)
- CEPH
- S3 (Amazon)

### Map-Reduce

Modelo de programación para procesar grandes conjuntos de datos, y procesarlos **de forma escalable**.

1. El usuario especifica una función `map` que **procesa un par clave/valor** para generar un conjunto intermedio de pares.
2. Se debe especificar también una función `reduce` que **combina** todos los valores asociados a la **misma clave**.

#### MAP

- Transforma nuestros datos. 
- Se aplica a **cada dato** del set.
- Puede ser paralelizada y distribuirse entre distintas máquinas del cluster.

#### REDUCE

- Combina los resultados del `map`.
- Es necesario procesar los datos de **todas las máquinas del cluster**.
- Reduce locales en paralelo y reduce **entre máquinas** mediante la etapa de `shuffle & sort`, para tener los datos con misma clave en los mismos nodos.  
- Las operaciones deben ser **conmutativas y asociativas**, para que puedan ser ejecutarse de forma distribuida.

#### Shuffle & Sort

- Se mueven datos de un nodo a otro.
- Mueve la salida de un `map` a un cierto equipo para que un reducer pueda procesar sus registros.
- Es la **fase más costosa** del Map-Reduce.
- Optimización para reducir la cantidad de datos a transmitir por la red.

### Apache Spark

- Sistema de procesamiento de distribuido.
- Posee un framework para resolver consultas con Map-Reduce.

#### Arquitectura

- Comunicación entre un driver y una serie de ejecutores (*executors*).
- Tareas (*jobs*) del driver se convierten en tareas para los executors.
- Los resultados de esas tareas **vuelven al driver**. 

#### Resilent Distributed Datasets (RDDs)

- Estructuras de datos que maneja Spark.
- Colecciones particionadas en un cluster.
- Guardados en **memoria o disco**.
- Reconstruidos automáticamente frente a fallos o demoras.
- Son creados a partir de **datos externos**.

**Operaciones sobre RDD**:

- **Transformaciones**: 
	- Crean un nuevo RDD a partir de otro existente. Se encadenan una atrás de la otra.
	- Son *lazy*: espera hasta que se definan acciones para realizarse.
	- Se cachean todas las participones (RAM o disco).
	- Algunas disponibles: Map, Filter, FlatMap, ReduceByKey, GroupByKey, Join.

- **Acciones**:
	- Devuelven un valor al driver luego de procesar los datos.
	- Es cuando varias transformaciones encadenadas finalmente se ejecutan.
	- Algunas disponibles: Collect, Reduce, Count, Take, TakeOrdered, First.

### Usar Spark con Python

#### Instalaciones e importaciones

Primero debemos instalar `pyspark`, que bajará las dependencias necesarias: `pip install pyspark`.
#### Acciones

- `rdd.count()`: obtiene la cantidad de registros del RDD.
- `rdd.take(n)`: obtiene los primeros `n` registros del RDD.
- `rdd.collect()`: obtener todos los registros del RDD. Si son demasiados, se va a sobrecargar el *driver*.
- `rdd.first()`: obtiene el primer registro de RDD.
- `rdd.takeOrdered(n, func)`: obtiene los primeros `n` registros en base a un orden indicado por la función `func`.
- `rdd.takeSample(replacement, n)`: obtiene una muestra de `n` registros del RDD. `replacement` es un booleano que indica si un registro puede ser elegido o no **más de una vez**.
- `rdd.reduce(func)`: obtiene **un solo registro**, combinando el resultado en base a la función `func` dada.
- `countByKey()`: cuenta ocurrencias de registros para cada clave. Los registros deben ser **tuplas de únicamente 2 elementos** (el 1ro la clave y el 2do el valor).

#### Transformaciones 

- `rdd.map(func)`: transforma cada registro en base a la función `func` dada.
- `rdd.filter(func)`: filtra registros en base a la función `func` dada. Nos sirve para descartar registros que no nos sirven (y para quedarnos con los que sí).
- `rdd.flatMap(func)`: similar a `map` pero cada registro puede **generar 0, 1 o más registros**.
- `reduceByKey(func)`: combina los registros de una misma clave basados en la función de Reduce `func`, que compara los valores asociados a esa clave. Esta debe ser **conmutativa y asociativa**.
- `groupByKey()`: agrupa los registros para cada clave. Solo se usa si es necesaria la información de cada registro y la cantidad por clave no es muy grande. Esta transformación es **costosa** (para agregaciones, usar `reduceByKey`).
- `rdd.distinct()`: **elimina registros duplicados** (todo el registro debe coincidir).
