## Clase 18 - IA 1

### 1. Introducción y Contexto

A diferencia de otros modelos de Machine Learning (como la regresión logística o XGBoost), los LLMs son relevantes incluso para quienes no trabajan directamente en ciencia de datos, debido a su impacto en el desarrollo de software y la gestión de proyectos. Se basa gran parte del contenido en las enseñanzas de **Andrej Karpathy**, figura clave en Deep Learning.

### 2. Las Tres Etapas de Desarrollo de un LLM

El desarrollo de estos modelos se divide fundamentalmente en tres fases:

- **Pre-training (Pre-entrenamiento):** Recolección masiva de datos y entrenamiento inicial del modelo para predecir el siguiente token.
- **Supervised Fine-Tuning (SFT):** Entrenamiento asistido para que el modelo aprenda a actuar como un asistente.
- **Reinforcement Learning (RLHF):** Refuerzo mediante feedback humano para moldear el comportamiento y evitar respuestas tóxicas.

### 3. Creación del Dataset y Web Crawling

Los LLMs se entrenan con volúmenes de información masivos provenientes de casi todo internet, incluyendo libros, Wikipedia, Reddit y foros. El proceso implica:

- **Web Crawling:** Programas que navegan y descargan el HTML de las páginas.
- **Filtrado:** Se eliminan URLs de sitios no deseados (apuestas, contenido adulto), se extrae solo el texto crudo, se filtra por idioma y se remueve la **PII (Personal Identifiable Information)** como DNI o nombres propios para proteger la privacidad.

### 4. Tokenización y el Algoritmo BPE

Los LLMs no procesan texto directamente en lenguaje humano, sino que hablan en **tokens** (representaciones numéricas).

- **Funcionamiento:** Un tokenizador traduce el prompt del usuario a números antes de que lleguen al modelo.
- **BPE (Byte Pair Encoding):** Es el algoritmo utilizado para construir el vocabulario. Comienza tratando cada carácter como un token y va fusionando los pares de tokens más frecuentes (por ejemplo, "N" y "E" para formar "NE") hasta alcanzar un tamaño de vocabulario fijo (como los 100,000 de GPT-4).
- **Importancia de los prefijos:** Separar palabras como "involuntario" en "in" y "voluntario" permite que el modelo entienda mejor las relaciones semánticas.

### 5. Entrenamiento e Inferencia

- **Entrenamiento:** El modelo se entrena maximizando la probabilidad de generar el **token correcto** dado un contexto previo (ventana de contexto). Son básicamente funciones matemáticas altamente parametrizadas que transforman un input en una cadena de tokens probables.
- **Inferencia:** Es el proceso de generación de respuesta, el cual ocurre **token a token**. En cada paso, el modelo calcula la "auto-atención" (self-attention) sobre los tokens existentes para predecir el siguiente, lo añade a la ventana de contexto y repite el proceso hasta generar un token especial de finalización.

### 6. Modelos Base vs. Modelos Instruct

- **Base Models:** Son los modelos que salen directo del pre-entrenamiento. Solo saben completar texto y no necesariamente responden preguntas; por ejemplo, si se les saluda, podrían responder como si fuera una carta o una historia en lugar de un diálogo.
- **Instruct Models:** Son modelos base sometidos a **Fine-Tuning (SFT)** con datasets de conversaciones humanas para que aprendan el rol de asistente (ping-pong de preguntas y respuestas).

### 7. Alucinaciones y Memoria

Las alucinaciones se definen como respuestas que no tienen sentido lingüístico o que no corresponden al contexto dado. Se mencionan dos tipos de fuentes de información para el modelo:

- **Bake Recollection:** Lo que el modelo "recuerda" de su entrenamiento inicial.
- **Working Memory:** La información presente en la ventana de contexto actual (como el código que un usuario le pasa para analizar).

### 8. Tool Calling (Uso de Herramientas)

Dado que los LLMs son generadores de texto y no motores de cálculo o búsqueda, se utilizan las **Tools**. Mediante protocolos (como RPC o MCP), el modelo puede emitir una etiqueta especial (ej. `search`) que un servidor externo interpreta, ejecuta la acción (buscar en Google o usar una calculadora) y devuelve el resultado al contexto del modelo para que este formule la respuesta final.

### 9. Razonamiento y Tokens Intermedios

Para resolver problemas complejos (como matemáticas), los modelos necesitan **tokens para pensar**. Obligar a un modelo a responder en un solo token un problema difícil suele llevar al error; permitirle "razonar en voz alta" generando pasos intermedios aumenta drásticamente la probabilidad de una respuesta correcta.

### 10. Reinforcement Learning from Human Feedback (RLHF)

Es la etapa final donde se utiliza un **modelo de recompensa** basado en comparaciones hechas por humanos. Esto sirve para "alinear" el modelo, penalizando comportamientos no deseados como la toxicidad o la agresividad, incluso cuando esos patrones estaban presentes en el dataset original de internet.
