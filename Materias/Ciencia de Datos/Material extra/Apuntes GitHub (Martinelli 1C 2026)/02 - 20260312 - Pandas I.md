## Clase 2 - Pandas I

**Análisis exploratorio de datos**: ver cómo los datos se relacionan, cómo son y de qué manera se conforman.

**Pandas**: biblioteca de Python que nos permite manejar datos de menor o mediana escala. 

### Uso de Pandas

Para importar la biblioteca:

```python
import pandas as pd # 'pd' es el alias
```

Para leer un archivo ***.csv*** con pandas, usamos el método `read_csv`, y guardamos el DataFrame en la variable `df`:

```python
df = pd.read_csv("archivo.csv")
```

Para visualizar el DataFrame, simplemente escribir `df` en la línea inferior, y para ver información acerca de las columnas/atributos de la tabla, utilizar `df.info()`.

### Acceso a columnas

Para acceder a una columna del DataFrame, llamada `columna1`:

```python
df.columna1     # opción 1
df["columna1"]  # opción 2
# Así se obtiene la serrie correspondiente a la columna 'columna1'.
```

- Se puede **mapear** columnas con funciones específicas para obtener nuevos resultados, usando el método `map()`. Es importante notar que el resultado del mapeo (la nueva serie generada) es ***completamente independiente*** del DataFrame original.

### Creación y modificación de columnas

- Para crear una nueva columna, se hace exactamente igual que cuando queremos acceder a una ya existente. Al escribir un nuevo nombre, se reconoce que se intenta crear una columna en vez de acceder a una. Si le pasamos un nombre de columna preexistente, sobreescribirá los valores anteriores con los nuevos.

Pandas tiene la opción de poder generar un nuevo DataFrame con menos columnas a partir del original. Si quisiéramos quedarnos solo con `col1` y `col2`, podemos escribir:

```python
nuevo_df = df[ ["col1", "col2"] ]
```

- Para generar estadísticas automáticas acerca del DataFrame, usamos el método `describe()`.

### Filtros

Para filtrar por **filas** en nuestra consulta, hacemos lo mismo que en la selección anterior de columnas, solo que en vez de poner los nombres de ciertas columnas, utilizaremos booleanos para realizar filtros que determinen si una fila cumplirá o no los requisitos para pasar:

```python
df[ [bool] ] # Devuelve las filas que cumplan con el booleano

df.loc[bool, [columns]] # Devuelve las filas que cumplen con el booleano, solo devolviendo las columnas especificadas en 'columns'.
```

### Agrupaciones y agregaciones

- Usaremos `groupby()` para agrupar distintas filas en base a datos parecidos de columnas determinadas. Luego de generar el grupo, debemos aplicar una **función de agregación** para formar un nuevo DataFrame. El método `groupby()` por sí mismo solo genera un grupo, y no un DataFrame.

- Podemos usar ***aggregate*** (`agg()`) luego del *groupby* para aplicar múltiples operaciones al agrupado que hemos hecho. Le pasamos un diccionario con todas las funciones relevantes para cada atributo perteneciente a ese grupo. 

### Labels de columnas y sobreescritura

Para obtener la lista de labels de las columnas del DataFrame:

```python
nombres_columnas = df.columns
```

Para sobreescribir completamente los labels del DataFrame:

```python
df.columns = [<nombre1>, <nombre2>, <nombre3>, ...] 
# La lista a sobreescribir debe ser de la misma longitud que la cantidad de columnas originales del DataFrame.
```

- Para hacerlo de manera amigable, sin tener que sobreescribir todo el índice, usamos el método `rename()`, usando el nombre original de la columna y el nuevo a sobreescribir.

### Índices

- Usamos el método `reset_index()` para eliminar el índice del DataFrame y volver al nombre original. El índice pasa a ser una de las columnas, la cual adopta su nombre inicial de agrupación.

```python
canciones.iloc[[0,3,6], [2,4]]
# Me permite quedarme con las filas de índices 0, 3 y 6, pero solo con las columnas 2 y 4 de cada una de esas filas. 

canciones.iloc[0:3, :]
# Me permite quedarme con las filas de índice 0 a 2 inclusive (la 3 no entra). Si ponemos ':' significa "todas", es decir, queremos todas las columnas de cada fila. Un 3er número (x:y:z) nos permite elegir el paso entre filas.
```

Con `loc()` debemos utilizar los nombres de las columnas sí o sí. El método `iloc()` nos permite usar los índices numéricos.
### Utilidades

Para obtener la cantidad de repeticiones de valores en una columna, incluso de manera ordenada, podemos utilizar el método `value_counts()` aplicado a una **serie**.

```python
canciones["Titulo"].value_counts()
# Me dará, de forma descendiente, los nombres de las canciones y su cantidad de repeticiones en el DataFrame (las más repetidas arriba).
```

Podemos obtener los n valores más grandes de una columna con el método de DataFrame `nlargest(n, column)`:

```python
canciones.nlargest(5, "Popularidad")
# Recibiremos las filas de las 5 canciones con mayor popularidad.

canciones.nsmallest(10, "Energia")
# Recibiremos las filas de las 10 canciones menos enérgicas.
```

**Contador de nulos**:

```python
canciones.isnull().sum() # Devuelve la cantidad de nulos existentes por cada columna.

canciones.isnull().sum().sum() # Devuelve el total de nulos de todo el DataFrame.
```
