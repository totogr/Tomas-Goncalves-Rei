## Clase 1 - Introducción a Data Science

La **ciencia de datos** es una rama de la computación que se encarga de entender, procesar y extraer valor a partir de los datos.

- Se juntan conceptos matemáticos, de ciencias de la computación, y del expertiz de dominios específicos.
- A partir de las tres cosas surgen intersecciones en común, como la investigación estadística, el procesamiento de datos, y Machine Learning.

Existen **roles** en los equipos de Data Science:
- Data Analyst: obtener y analizar información, crear métricas
- Data Scientist: modelizar información y trabajar con análisis exploratorio
- Data Engineer: foco en Computer Science, tener disponibilidad de datos
- Machine Learning Engineer: llevar a producción los modelos, para que escalen a millones de usuarios

**Áreas de Conocimiento**
- Big Data: grandes volúmenes de datos, trabajarlos de forma distribuida (Spark, Databricks)
- Machine Learning
- Deep Learning
- Análisis de Redes Sociales
- Sistemas de Recomendación
- Procesamiento de Lenguaje Natural
- Visualización de Datos
- Algoritmos de Streaming
- Bases de Datos (SQL)
- No SQL (Cassandra, Mongo, etc)

Se puede pensar a la ciencia de datos como un ***proceso***. Nos interesa buscar respuestas a preguntas acerca de los datos que nos lleven a ciertas conclusiones.

1. **Hacer una pregunta interesante**: pensar lo que nos gustaría obtener a partir de la información que tenemos. 

Se definen distintos problemas para realizar la pregunta:
- **Regresión**: predecir el valor de una variable numérica y continua a partir de un conjunto de datos.
- **Clasificación**: predecir el valor de una variable discreta (de pocos y finitos valores) a partir de un conjunto de datos.
- **Clustering**: dividir de forma automática un conjunto de datos en distintos grupos.
- **Recomendaciones**: se le quiere recomendar a usuarios cosas que le pueden llegar a interesar.
- **Sistemas de consulta**: motores de búsqueda que encuentren resultados acordes al pedido de los usuarios.

2. **Conseguir los datos**: requiere bastante tiempo de dedicación. Existen herramientas o sistemas externos que permiten obtener los datos que necesitamos. Queremos limpiar y depurar los datos, eliminar anomalías en ellos.

3. **Explorar los datos**: llevar a cabo un análisis exploratorio para hacer análisis estadísticos acerca de los datos. Aquí se adquiere un entendimiento profundo de los datos.

4. **Modelar los datos**: aplicar distintos algoritmos que moldeen acordemente los datos ya analizados en los pasos anteriores, para obtener respuestas a la pregunta hecha al principio.

5. **Comunicar y visualizar los resultados**: hacerle saber de forma sencilla a las demás personas, a través de reportes o visualizaciones, los resultados obtenidos a partir del análisis de los datos. Posiblemente surjan nuevas preguntas en este paso.
