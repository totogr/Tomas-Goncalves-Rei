## Clase 5 - Pandas III

### Cambios de estructura con *Stack* y *Unstack*

- Con `stack()` toma el nivel más bajo de índices de **columna**, y lo convertirá en **índice de fila** (también el nivel más bajo). 
- Con `unstack()` hacemos al revés: toma el nivel más bajo de índices de **fila**, y lo convierte en el **índice de columna** más bajo. 

Por *default* toma los niveles más bajos, pero le podemos pasar un número que represente el **nivel de índice deseado**.

Puedo obtener las columnas por nivel de índice usando el método de *columns* `get_level_values()`.

Luego de hecha la transformación con *stack* o *unstack*, se puede resetear los índices para dejarlo en formato de tabla con `reset_index()`.

### Trasposición

Con el método `T` se puede trasponer el DataFrame: **llevar las filas a las columnas, y las columnas a las filas**.

### Pivot

- Definir qué índice se quiere usar. Se le pasa el **nombre de una columna** (atributo `index=`).
- Luego se le pasa las columnas que resultan del *pivot* (atributo `columns=`).
- Finalmente indicamos los **valores** para cada intersección entre fila y columna (atributo `values=`).

**No debe haber valores duplicados, ya que no podríamos elegir alguno de ellos**.

### Pivot Table

El método `pivot_table` permite agregar al final una **función de agregación** para resolver el problema de `pivot()`.

### Merge

El método de Pandas `merge()` sirve para juntar dos o más DataFrames en uno solo. 

- `Inner`: junta con las coincidencias de ambos.
- `Left`: retorna todas las filas del izquierdo y rellena con *NaN* las del derecho que no coinciden.
- `Right`: retorna todas las filas del derecho y rellena con *NaN* las del izquierdo que no coinciden.
- `Outer`:  junta todas las filas de ambas tablas y rellena con *NaN* donde no haya coincidencias.

### Crosstab

Indica la **cantidad de ocurrencias** par cada intersección entre resultados de **filas y columnas**.

Con el método de Pandas `crosstab()` le indicamos:
- Las filas con el atributo `index`.
- Las columnas con el atributo `columns`.

Para ambos atributos debemos usar el formato `df['...']`, y no solo el nombre de la columna a usar.

Reemplaza la necesidad de hacer un gran `pivot_table` utilizando el atributo `aggfunc='size'`. Es más fácil de ver con el *crosstab*, ya que por *default* cuenta la cantidad de ocurrencias (el tamaño o *size*).
