# Ciencia de Datos

Material de la materia **Ciencia de Datos**: clases teóricas, clases prácticas, guías de ejercicios y bibliografía.

Los profesores van subiendo material clase a clase (slides y archivos) en **Clases Teóricas** y **Clases Prácticas**. Esta carpeta se va actualizando a medida que se agrega contenido.

## Contenido

| Carpeta / Archivo | Descripción |
| --- | --- |
| [`Guías de estudio/`](Gu%C3%ADas%20de%20estudio/) | Guías para llegar a cada clase con el tema entendido (analogías, diagramas, tablas y autoevaluación). |
| [`Clases Teóricas/`](Clases%20Te%C3%B3ricas/) | Slides por unidad: introducción a la materia, visualización de datos, introducción a la ciencia de datos, ingeniería de features, árboles, ensambles, KNN y SVM, reducción de la dimensionalidad (PCA, MDS/PCoA, t-SNE, ISOMAP) y redes neuronales. |
| [`Clases Prácticas/`](Clases%20Pr%C3%A1cticas/) | Notebooks de práctica por clase: Pandas y EDA, regresión, clasificación, clustering, feature engineering, árboles, ensambles, KNN y SVM, redes neuronales y reducción de dimensionalidad. |
| [`Guías de Ejercicios/`](Gu%C3%ADas%20de%20Ejercicios/) | Guías de ejercicios por tema (Pandas). |
| [`Bibliografia/`](Bibliografia/) | Libros de referencia de la materia (Machine Learning con Scikit-Learn, Keras y TensorFlow). |
| [`Material extra/`](Material%20extra/) | Material de terceros: parciales de años anteriores de la cátedra, apuntes y resúmenes de otros alumnos (con su fuente). Lo que sirve se vuelca, revisado, en las guías y el resumen. |
| `Calendario 2do 2026.xlsx` | Calendario del cuatrimestre con fechas de clases y evaluaciones (versión actualizada: el **parcial pasó al jueves 29/10** por el paro del 15/10; recuperatorio 19/11). |
