# Sprint 3

## Objetivos
- Dotar a la plataforma de autonomía y herramientas de autogestión, evolucionando más allá del flujo de reserva básico inicial.
- Para el Cliente:
    - Habilitar la búsqueda y el filtrado eficiente de profesionales.

    - Permitir la gestión activa del ciclo de vida de sus turnos (visualizar, reprogramar y cancelar).

    - Desarrollar la funcionalidad para calificar el servicio recibido una vez finalizado el turno.

- Para el Profesional:

    - Brindar control total sobre su disponibilidad diaria y la visualización de su agenda.

    - Permitir la configuración y gestión de turnos grupales.

    - Habilitar la opción de cancelar reservas en caso de eventualidades.

    - Proveer acceso a un panel con estadísticas clave sobre el rendimiento de su negocio.

## Resultados obtenidos
- Gestión avanzada para el Profesional: Se implementó el control de agenda y disponibilidad, incluyendo la funcionalidad de turnos grupales y la gestión de cancelaciones, dándole al profesional las herramientas necesarias para administrar su tiempo.
- Cumplimiento del alcance planificado: Se alcanzó la totalidad de los objetivos establecidos para la iteración, consolidando la autonomía operativa de la plataforma y reduciendo la dependencia de flujos manuales para ambos perfiles de usuario.
- Módulo de gestión para el Cliente: Se implementaron y probaron con éxito las herramientas de búsqueda y filtrado avanzado. Adicionalmente, se habilitó el ciclo de vida completo de las reservas, otorgando al cliente la capacidad de visualizar, modificar y cancelar sus turnos de manera autogestionada.
