# Trabajo por sprints

El proyecto se desarrolló a lo largo de **4 sprints** siguiendo un marco de trabajo ágil (Scrum). En cada sprint se asignaron los roles de **Product Owner (PO)**, **Scrum Master (SM)** y **QA**, además de las tareas de desarrollo.

## Resumen de sprints

| Sprint | Foco principal | Carpeta |
|--------|----------------|---------|
| Sprint 1 | Configuración de la arquitectura, modelo de base de datos e implementación inicial del registro. | [sprint-1/](sprint-1/) |
| Sprint 2 | Desarrollo de la funcionalidad básica de reserva de turnos, estableciendo el flujo principal de interacción en la plataforma. | [sprint-2/](sprint-2/) |
| Sprint 3 | Consolidación de todo el flujo de reservas e integración de módulos adicionales (sistema de calificaciones y panel de estadísticas). | [sprint-3/](sprint-3/) |
| Sprint 4 | Estabilización final del sistema e implementación de lógicas de control avanzado: automatización de listas de espera y notificaciones. | [sprint-4/](sprint-4/) |
