# Sprint 1

## Objetivos
- Poner en marcha el proyecto y establecer la **separación de responsabilidades** entre
  base de datos, backend y frontend.
- Asegurar que la arquitectura de la aplicación sea capaz de gestionar, distinguir y procesar 
  correctamente los perfiles de cliente y profesional desde el momento del registro.
- Configurar las herramientas, repositorios y flujos de trabajo necesarios para que el equipo 
  pueda colaborar de manera eficiente, integrando el control de versiones (Git/GitLab) y las 
  prácticas de documentación definidas durante la fase de planning.

## Resultados obtenidos
- Despliegue inicial y arquitectura: Se inicializó el proyecto estableciendo con éxito una clara separación de responsabilidades estructurales entre las capas de base de datos, backend y frontend.
- Gestión de roles y autenticación: Se implementó la funcionalidad básica operativa, permitiendo el registro e inicio de sesión de los usuarios. El sistema ahora es capaz de procesar, distinguir y gestionar correctamente la asignación de perfiles de "Cliente" y "Profesional" desde el primer punto de contacto.
- Consolidación del entorno de trabajo: Se configuraron de manera definitiva las herramientas de colaboración, los repositorios en Git/GitLab y los flujos de trabajo del equipo, garantizando el cumplimiento de las prácticas de documentación definidas en la fase de planning.
